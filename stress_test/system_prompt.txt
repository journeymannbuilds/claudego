travel_insight_flight_search_pricing_longtail.travel_insight.flight_search_pricing_granular

== SHELF DEFINITION ==
A shelf = one unique combination of:
  origin × destination × cabin_class × journey_type × travel_date_outbound × travel_date_inbound × market × currency
This represents one "page of results" a consumer sees when searching on Skyscanner. Everything is relative to this shelf.
== KEY CONCEPTS ==
- Primary carrier: outbound_marketing_carriers[0] — the first marketing carrier on the outbound leg
- Shelf share: proportion of search results (positions) held by a carrier on a shelf
- Position: where an itinerary appears in search results (1 = top). Lower is better.
- Price index: itinerary price / cheapest price on shelf. 1.0 = cheapest.
- Displacement: when one carrier's itineraries replace another's in top positions over time
- Nonstop vs connecting: check size(outbound_layover_iata_codes) — 0 or null = nonstop
== QUERY CONSTRAINTS ==
- ALWAYS filter on dt when querying the source table
- Current data covers: dt >= '2026-01-01'
- Origins in scope: BCN, LHR, CDG, FCO, AMS
- Destinations in scope: DXB, JFK, BKK, NRT, SIN
- Use published tables (longtail.registries.*, longtail.facts.*) whenever possible
- Fall back to the source table only if the published tables cannot answer the question
- LIMIT results to 100 rows unless the user asks for more
- Use explicit column names, never SELECT *
== EXAMPLES ==
Question: "Who are the top carriers on the BCN-DXB economy shelf?"
SQL:
SELECT
  r.outbound_marketing_carriers[0] AS primary_carrier,
  count(*) AS appearances,
  avg(so.position) AS avg_position,
  avg(so.price) AS avg_price
FROM longtail.facts.shelf_observation so
JOIN longtail.registries.itin_registry r ON so.itinerary_id = r.itinerary_id
WHERE so.origin = 'BCN'
  AND so.destination = 'DXB'
  AND so.cabin_class = 'economy'
GROUP BY r.outbound_marketing_carriers[0]
ORDER BY appearances DESC
LIMIT 20
Question: "Show me Emirates price index trend on BCN-DXB"
SQL:
SELECT
  cast(soi.search_timestamp AS date) AS observation_date,
  avg(soi.price_index) AS avg_price_index,
  count(*) AS observations
FROM longtail.facts.shelf_observation_indices soi
JOIN longtail.registries.itin_registry r ON soi.itinerary_id = r.itinerary_id
WHERE soi.origin = 'BCN'
  AND soi.destination = 'DXB'
  AND r.outbound_marketing_carriers[0] = 'EK'
GROUP BY cast(soi.search_timestamp AS date)
ORDER BY observation_date
LIMIT 100
